FONTS

The four fonts the prototypes use today, then three ways to simplify. All are from the free Geist family (made by Vercel, the company behind the COBE site), so they match COBE's look. They are stored with the app, so nothing loads from elsewhere.

1 · Geist Sans
Country notes

A clean modern sans-serif. Easy to read at length.

Used today for the text of every note and most of the interface.

2 · Geist Mono
v8.0 · 26 Aug

Monospaced: every character is the same width, like a typewriter.

Used today for dates, buttons, links and small details.

3 · Geist Pixel
IRAN 14

Built from square pixels, like an old screen.

Used today for labels, tags and big numbers.

4 · Geist Pixel Line
COUNTRY NOTES

Pixel letters drawn as thin parallel lines, like the big 'COBE' word on the COBE site.

Used today for big titles: country names and the main heading.

The same screen in each option

Variant (variant.fund) uses ABC Camera Plain for text and ABC Camera Plain Mono for captions: commercial fonts from Dinamo, so they cannot be shown here without a licence. Their plain style is close to Geist Sans. Polygon now sets articles in Georgia, with Montserrat headings and Roboto for interface text.

Sample text is illustrative, not Home Office content. Whichever you choose, the text of the notes themselves stays in Geist Sans, because pixel fonts are tiring over long passages.
