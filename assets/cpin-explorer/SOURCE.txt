CPIN Explorer's own mark (product icon, alongside the Roberts Macros mark in the footer).

The mark is the site's globe in miniature: the same dots in the same places (COBE's lattice and land map),
at the globe's opening view, Africa and the Middle East. In the header it is drawn live by
prototypes/shared/brand-mark.js, which turns it to the country in hand and marks that country with a dot;
the files here are the same picture at the opening view, for where a script cannot draw it.

  mark.svg      generated by web/build-mark.mjs (cd web && npm run mark) from prototypes/shared/mini-globe.js;
                a <symbol id="mark"> drawn in currentColor, so pages colour it with CSS:
                <svg><use href=".../mark.svg#mark"/></svg>. The pages carry it as the header mark's starting
                picture; a test checks it is dot for dot what the script draws.
  favicon.svg   generated with it: the same mark in the site's blue, lighter in dark mode
  mark-512.png  mark.svg at 512 px in the site's blue (#2a3cf5) on transparent, rendered in Chrome
                (3 Oct 2026); used in the header of the Word export. Re-render it if mark.svg changes.

History: on 3 Oct 2026 the owner chose a dotted globe (option A of three: mark-dots.svg, mark-pin.svg,
mark-wire.svg, kept here with prototypes/brand/ for the record) and then asked for the mark to be a
miniature of the globe's own view, which is what mark.svg now is.
